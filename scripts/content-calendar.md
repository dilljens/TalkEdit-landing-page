# Content Calendar — TalkEdit Blog

## Strategy
- Publish **1 post per month** (not weekly — research shows weekly publishing
  doesn't help for non-time-sensitive topics, and quality > quantity)
- Each post targets a specific keyword cluster with clear search intent
- Each post links internally to 2+ other posts (builds topical authority)
- After 12 posts, review which are getting traffic and double down

## Monthly Workflow
1. Choose next post from calendar
2. Research: check SERP for target keyword (what's already ranking)
3. Write 800-1500 words (no padding — cover the topic thoroughly)
4. Add 1-2 internal links to existing posts
5. Check meta title (60 chars max) + description (160 chars max)
6. Run through seo-check.sh
7. Deploy
