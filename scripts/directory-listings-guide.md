# Directory Listings Guide — TalkEdit

Goal: Get listed on sites that already rank for "descript alternative" and
"best video editor" searches. Each listing is a backlink + referral traffic.

---

## 1. AlternativeTo — Most Important (already have checklist)

- URL: https://alternativeto.net
- Time: 5 min
- Why: AlternativeTo pages rank top 3-5 for "alternatives to [product]"
- Full guide: see `scripts/alternativeto-checklist.md`
- **Key**: The "alternative to Descript" connection is the whole point

---

## 2. Slant.co — Second Most Important

- URL: https://slant.co
- Time: 5 min
- Why: Slant ranks for "best [category] for [use case]" queries

### Steps:
1. Go to slant.co → "Add a recommendation"
2. Product name: TalkEdit
3. URL: https://talk-edit.com
4. Category: "Video Editing Software" or "Podcast Editing Software"
5. Description (paste):
> An offline AI-powered video editor for podcasters and long-form creators.
> Edit video by editing text — delete words to cut, mute, speed up, or
> adjust gain. 100% offline, one-time $49, no subscription. Handles
> 3-hour files without lag. Features include AI transcription, filler
> removal, animated captions, and Smart Clean audio processing.

### After listing:
- Vote for TalkEdit in relevant comparisons
- Add a "pro" (TalkEdit is offline, one-time payment, handles long files)
- Add a "con" (no cloud collaboration, no mobile app)

---

## 3. G2.com

- URL: https://g2.com/products/create
- Time: 10 min
- Why: G2 pages rank for "best [category] software"
- Category: "Video Editing Software" or "Audio Editing Software"

### Steps:
1. Create a G2 account
2. "Add Product" → fill in TalkEdit details
3. Pricing: select "One-Time Purchase" → $49 (Pro) or $99 (Business)
4. Category: "Video Editing Software" (primary)
5. Features: check all that apply from the list

### Note:
G2 shows ratings based on user reviews. Once you have 2-3 user reviews
(even from beta testers), the page becomes much more effective.

---

## 4. Capterra

- URL: https://www.capterra.com/register-new-product
- Time: 10 min
- Why: Capterra is the other major software review directory
- Same process as G2 — create listing, fill in details, add screenshots

## 5. Product Hunt (re-launch or update)

- URL: https://www.producthunt.com
- Time: 15 min prep + launch day

### If already launched:
1. Update the listing with new screenshots (show the current UI)
2. Add a comment about recent updates (offline AI, long file support, etc.)

### If not launched (new launch):
1. Create a Product Hunt account (or maker account)
2. Prepare:
   - Tagline: "Edit video by editing text — offline AI video editor for podcasters"
   - Description: highlight long file handling, one-time price, privacy
   - Screenshots: 3-5 showing the interface
   - First comment: launch story ("Why I built TalkEdit")
3. Launch on a Tuesday-Thursday morning (Pacific time) for best visibility
4. Share on Twitter/Reddit communities on launch day
