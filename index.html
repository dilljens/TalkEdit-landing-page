Frequently asked questions

Is it really 100% offline?

Yes. Transcription, AI features, and export all run locally. No data ever leaves your machine. No account required. The only time it touches the network is downloading Whisper models (optional) or if you connect to a local Ollama instance.

How long can my videos be?

TalkEdit handles hour+ files without issue. The transcript uses virtualized rendering and the waveform uses chunked loading — no lag, no crashes. We regularly test with 2-3 hour podcast recordings.

What's the refund policy?

30-day money-back guarantee, no questions asked. If TalkEdit doesn't work for you, email us and you'll get a full refund.

What formats are supported?

Input: MP4, MKV, MOV, AVI, WebM, M4A. Export: MP4 (H.264/H.265), MOV, WebM, WAV. Captions: SRT, VTT, ASS. Resolutions from 720p to 4K.

Which platforms are supported?

Windows, macOS (Apple Silicon), and Linux. Download the right build for your platform above. All three are fully supported with the same features.

Do I need a powerful GPU?

No. Transcription works on CPU (slower but usable). GPU (CUDA) speeds it up significantly. AI features use lightweight models that run on any modern machine with 8GB+ RAM.
